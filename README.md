# MySpaceMusicCatalogue

A type-safe PostgreSQL database binding library generated by
[pGenie](https://pgenie.io), targeting Java 21.

## Statements

- `InsertAlbum`
- `InsertMultipleAlbums`
- `SelectAlbumByFormat`
- `SelectAlbumById`
- `SelectAlbumByName`
- `SelectAlbumRows`
- `SelectAlbumWithFilters`
- `SelectAlbumWithTracks`
- `SelectGenreByArtist`
- `SelectGenreByPath`
- `UpdateAlbumRecordingReturning`
- `UpdateAlbumReleased`

## Custom Types

- `Album`
- `AlbumFormat`
- `DiscInfo`
- `RecordingInfo`
- `TrackInfo`

## Usage

Add the generated sources to your Maven project alongside the required runtime
dependency:

```xml
<dependency>
    <groupId>io.pgenie.artifacts.myspace</groupId>
    <artifactId>music-catalogue</artifactId>
    <version>1.0.1</version>
</dependency>
```

Open a session from config:

```java
var config = MusicCatalogueConfig.defaults(
    "jdbc:postgresql://localhost:5432/mydb?sslmode=require",
    "app",
    "secret");

try (var session = new MusicCatalogueSession(config)) {
    ...
}
```

`MusicCatalogueSession` is `AutoCloseable`, manages a HikariCP connection pool
internally, and emits OpenTelemetry spans/metrics and SLF4J logs.

Execute a statement:

```java
var result = session.execute(new InsertAlbum(...));
```

Run work inside a transaction:

```java
session.transaction(tx -> {
    tx.execute(new InsertAlbum(...));
    tx.execute(new UpdateAlbumReleased(...));
    return ...;
});
```

Transactions automatically retry serialization failures and deadlocks.

Errors are surfaced as checked `SQLException`s propagated directly from the
underlying JDBC calls.

Health check:

```java
session.healthCheck();
```

## Building

```bash
mvn verify
```

## Running Tests

Integration tests use [Testcontainers](https://testcontainers.com/) to spin up a
PostgreSQL container automatically. Docker must be available on the host.

```bash
mvn failsafe:integration-test failsafe:verify
```
